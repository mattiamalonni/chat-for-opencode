The chat lives in the **OpenCode** view in the Secondary Side Bar. Type a prompt and press **Enter** to send it. While the agent works, Enter queues the next message and **Ctrl/Cmd+Enter** sends it immediately.

Useful shortcuts:

- **Ctrl/Cmd+Alt+O** — focus the chat
- **Ctrl/Cmd+Alt+S** — quick switch session
- **Ctrl/Cmd+Alt+F** — search all conversations
- **Ctrl/Cmd+N** — new session (while the chat has focus)
