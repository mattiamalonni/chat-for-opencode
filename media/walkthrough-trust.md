OpenCode runs a local `opencode serve` process for each workspace folder. For that reason the extension works in **limited** mode inside an untrusted workspace: the server is not started and settings such as `opencode.executablePath` are ignored.

Click **Manage Workspace Trust** and trust the folder you want to work in. Once trusted, the extension connects automatically; you can come back to this walkthrough at any time from **Help → Welcome → Get started with OpenCode**.
