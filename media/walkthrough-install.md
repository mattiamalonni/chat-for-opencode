The extension controls the OpenCode **v2** CLI, so the `opencode` executable must be available on your `PATH`.

**macOS / Linux**

```bash
curl -fsSL https://opencode.ai/v2/install | bash
```

**Windows** — follow the platform-specific instructions at https://opencode.ai/docs/#installation (PowerShell or WSL both work).

Click **Show install command** to copy the command (Unix) or open the instructions (Windows), then **Retry** to reconnect without restarting VS Code. If you use a custom location, set `opencode.executablePath` in the extension settings.
